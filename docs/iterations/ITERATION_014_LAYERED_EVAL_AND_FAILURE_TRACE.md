## 设计取舍与限制

- 不设置掩盖边界错误的加权总分；每项要求全过的严格通过率与分层诊断并列。
- 用确定性行为测试评分，避免由模型自我声明 completed 或未经校准的 LLM judge 决定正确性。
- 同一任务独立重复，每个 route 分别计算实测 pass@k/pass^k；小样本不做能力排名。
- 缺失用量不填零；不设置模型价格、不声称货币成本下降；输入 Token 未硬封顶。
- 错误/blocked 项关联具体 Trace 行和最终文件；关联事件不宣称是确定因果根源。
- 旧成绩保留，重评分生成新报告；不修改 Key、URL、实际角色配置或普通 Session 账本。
- 仅两个受限纯函数任务，不能证明广泛仓库能力、安全沙箱或自动规划/审查已可靠。
